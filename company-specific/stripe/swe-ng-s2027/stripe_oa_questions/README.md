# Stripe OA Questions

These folders reproduce the FastPrep question text supplied by the user and
provide Python starter files plus comprehensive public tests.

| Problem | Difficulty | Stage | Reported |
|---|---|---|---|
| [Deployment Window Scheduler](deployment_window_scheduler/) | Hard | Intern, New Grad, Full-time OA | October 5, 2026 |
| [Incident Monitor](incident_monitor/) | Hard | Full-time, New Grad OA | October 1, 2026 |
| [WebSocket Load Balancer — Parts 1–5](websocket_load_balancer/) | Hard | Intern, New Grad OA and Onsite | September 16, 2026 |

Each problem folder contains:

- `README.md` — the supplied problem statement and deterministic test contract;
- `solution.py` — the function to implement; and
- `tests/test_solution.py` — tests grouped by problem part.

Run a problem from its folder with:

```bash
pytest -q
```
